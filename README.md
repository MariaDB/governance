# MariaDB Governance

This repository contains the governance, policies, and related documents for the MariaDB project.

## Purpose

The goal of this repository is to provide a clear, transparent home for the rules and processes that help the MariaDB community and contributors collaborate effectively. It includes the following documents:

- [Governance of MariaDB Server](governance.md)
- [Code of Conduct](code-of-conduct.md)
- [Response Times](response-times.md)
- [Committers](committers.md)
- [Maintainers](maintainers.md)
- [Security policy](security-policy.md)
- [Deprecation policy](deprecation-policy.md)
- [Quality Development Rules](quality-development-rules.md)
- [AI contribution policy](ai-policy.md)

Changing to this repository follow the process described in [Governance. Decision making](governance.md#3-decision-making) and [Maintainers. Voting and Recording decisions](maintainers.md#voting-and-recording-decisions)
